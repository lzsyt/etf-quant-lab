# 模拟交易与风险控制说明

每个策略拥有独立100000元虚拟账户。账户之间不能合并成一条策略收益。系统不含证券账户凭据、真实下单API或真实资金接口。

日终流程在北京时间17:30入数据库队列：核对可信交易日历、增量行情、检查完整性、依次结算缺失日期、对账已到期预测、采集新闻、执行已授权LLM分析、生成1/5日预测并冻结。机器学习采用当前模型版本；规则、LLM和融合各自独立保存。无合格新闻或API失败只记录缺失，不生成替代财经分析或虚构预测。

预测记录保存行情日、输入截止时间、实际生成时间、模型/特征版本、输入批次及概率或分数。有效记录一经插入无法改删。某次分析缺失时不插入虚假的预测，待条件恢复才可能产生新的有效记录；已有业务键绝不覆盖。

模拟结算要求前一交易日的完整策略预测已经在当前交易日09:30北京时间前生成。后来补出的预测不能拿来假设早盘成交。没有可靠盘中行情，全部成交明确为日线开盘估计；后续取得真实日线再落账，不宣称具有盘中实盘撮合能力。

V1.0自动模拟账户默认使用1日预测驱动每日目标仓位；5日预测独立保存、展示和到期对账。历史回测API可选择预测窗口，不能把5日预测记录误解为已经实现另一组独立的5日持仓账户。

默认风险：单ETF20%、总仓位40%、单笔买入5%、单日新增买入10%、当日净值损失2%暂停新增、历史峰值回撤10%锁定策略。买入前按照当时现金、持仓、费用和最新估值检查；锁定后允许降低风险的卖出，但不能保证已有持仓不会进一步下跌。锁定状态持久化，不通过重启清除。

金额结算使用Decimal，精确到分；持仓按取得日期保留批次，遵守各ETF具体T+1及买入单位。现金不足含手续费时缩减手数；涨跌停、成交量不足、停牌与异常价格会拒单。分红已核实时，除息日先记应收，支付日才变为可用现金；拆分不创造额外成本。

同账户结算以事务锁和最后结算日期保护。现金、持仓投影、订单、成交、费用、净值和风险事件原子提交；并发测试已验证只发生一笔账。任务重复、服务重启和部署不会删除账户历史。缺行情时不推进该账户结算日，补齐后按日恢复。

暂停策略仅停止新订单，仍更新持仓估值；启用不会清空历史。风险参数每次修改必须有原因并另存历史版本。界面可查看拒单、成交费用、风险事件和全部修改记录。

截至首次本地验收，11个账户完成初始估值、54条规则/ML预测冻结，尚未经历未来交易日。因此没有多日实时盈利验证，也没有可声称的上线后胜率；页面将历史研究与未来模拟分开展示。
