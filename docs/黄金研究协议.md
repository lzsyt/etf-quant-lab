# 实物黄金中长期研究协议 V1

适用范围：ETF Quant Lab 内的黄金研究增量。仅研究和成本情景测算，不连接证券账户、真实委托或实物购买接口。黄金与ETF使用同一鉴权、Java/Python服务、PostgreSQL、持久任务和费用总账，数据、模型、预测、解释分别存入独立 `gold_*` 表；不创建黄金模拟交易账户。

每条观察保存：观察日、十进制值、单位、来源URL、公开时间及精度、系统抓取时间、内容修订、质量、原字段。未知历史首次发布时间留空；首次导入时间绝不冒称历史首次公开时间。修订追加、重复导入复用原记录，原记录由不可变触发器保护。

2026-10-26下载SGE当前版本为2016-12-19至2026-10-26共2,388条，约9.85年，未宣称达到10年。17条官方OHLC关系异常原样保留，仅收盘进入模型；没有自行改价或删除日期。观测日历保存交易日期及摘要，并列出长间断；尚未逐年独立核实休市公告，因此不能保证所有来源缺日均已排除。

来源健康分别为正常、部分覆盖、空、过期、失败、不可用；失败保留上次有效日期。国内基准最大年龄10自然日，FRED宏观14日，国际月均62日；界面显示实际观察日期和年龄，阈值内不代表实时成交行情。

## 标签、验证与冻结

独立目标为未来63、126个已观察SGE交易日：`y_h=P_target/P_reference−1`。页面写“约3个月（63交易日）”“约6个月（126交易日）”。参考为已结束的官方日收盘；[交易所合约说明](https://www.sge.com.cn/cpfw/Au9999)日间交易结束15:30。研究生成晚于参考收盘，不宣称用户可在该事后已知价格买入。

历史标签按真实观测会话索引计算，不用自然日。未来目标日期暂用工作日估计，显式标记日历未确认；到期按照实际追加观察计算，并保留实际目标日及日历边界，原预测不改写。

首版特征为21/63/126日收益、21/63日波动、相对63日均线距离。不使用今天重新阅读的历史新闻，也不将无法证明发布时间/修订历史的宏观变量混入历史训练。当前宏观卡片和条件情景与数值模型分开。

基线为仅训练期估计的常数上涨频率、训练期多数类方向、收益分位数，并单列零收益误差。候选为单线程固定60棵小型LightGBM，不做搜索或深度学习。中位收益由中位数回归及独立校准残差中位数得到；上涨概率为分类器经顺序独立段Platt校准的 `P(y_h>0)`；区间为独立校准残差10%/90%分位数，名义80%未来价格预测区间，不是均值置信区间。

每折按时间顺序训练→校准→测试：训练标签结束早于校准首日，校准标签结束早于测试拟合日；不随机打散。固定滚动段之后保留最终504个成熟参考日，不按成绩调整参数、测试区间或阈值。上线工件在评估后按相同固定规则重新拟合，角色与历史折工件分开。报告每折时间、成熟样本数、近似独立窗口、Brier、准确率、MAE、覆盖率及区间宽度；另外按固定每63/126会话抽样检验非重叠结果，不把日标签当独立半年实验。

校准缺少两类的足够样本时概率及其指标为空，不固定填0.5。当前模型能拟合校准器不代表最终历史测试已验证校准效果；当前概率和区间始终标记实验、尚无稳定优势。

冻结链包括观察修订→特征快照→训练输入压缩文件→模型工件及SHA256→代码版本/源码摘要/依赖版本→拟合与生成时点→预测记录→到期追加结果。模型、观察、预测和实际结果不更新覆盖；同参考日/模型/期限重复任务不新增预测。历史回放与上线真实前瞻分开，未到期显示待验证。

## 条件情景与新闻

12个月仅展示偏强、偏弱、相互抵消三组条件及失效条件：实际利率、汇率、需求等影响路径是机制假设，未给出可校准数值、目标价或概率。不存在个人持仓或真实渠道历史溢价时不生成实物历史收益回测。

黄金解释复用既有来源快照、双时间、内容去重、V2.1.2证据切片及服务端原文映射。黄金域单独定义长期相关性；纪念币、零售活动与“提及黄金”不自动成为利多。DeepSeek只选冻结ID并解释可能机制、反向因素、不确定性、失效条件，不能改数值预测或套用ETF70/30融合。

每周至多一批、每批最多一次HTTP，共用原 `llm-budget:北京时间日期` 锁及 `api_call_cost` 预算1美元/日。ETF优先；黄金指纹、任务及费用键含 `GOLD_LONG_TERM`。默认黄金付费解释关闭，启用仍只能用已有额度；无证据、预算不足或失败明确缺失，保留旧结果日期，不编造新闻或自动无限重试。

## 实物成本

不默认用户持仓。金额使用BigDecimal；买入每克价格按用户输入克数计费。回购按Au99.99成色0.9999换算：毛重输入时计价克数 `q×成色÷0.9999`；纯金克数输入时为 `q÷0.9999`。具体渠道是否采用该规则须用户核实。

费用顺序固定：基准价先扣比例，再减每计价克扣减，最后减固定卖出费用。全包总成本与每克价格二选一；已包含的溢价和买费不重复加收。设换算后计价克数为 `q_e`、比例扣减为 `r`、每克扣减为 `d`、固定卖费为 `f`：

```
回购净额 = q_e × [基准价 × (1−r) − d] − f
保本基准价 = [(买入总成本+f)÷q_e + d]÷(1−r)
```

测试专用算例：基准1000、实际买价1020、回购扣减10、无其他费用、0.9999成色毛重，保本1030元/克。该算例不进入真实行情。真实渠道报价需渠道和含时区时间；超过24小时标过期。预测区间换算净收益明确假设回购规则不变，无对应分布则不展示扣费后盈利概率。

## 接口、调度和运行

- 页面 `/#/gold`；GET `/api/gold/overview`、`/predictions/{id}` 和 `/import/template`只读。刷新不采集、训练或收费。
- POST `/api/gold/cost`纯计算不保存持仓。CSV模板只有表头，POST `/import`强制标为未核验，不混入官方训练基准。
- 管理初始化 `/data/import`、`/models/import`、`/tasks`沿用登录和CSRF；单批观测不超过20,000条，实际初始化分批2,000条。
- 默认北京时间每日21:00增量，周一22:30预测、每月固定周期重训；停机后补入同一周期键。必要数据不足先等待，重试有上限。
- 黄金worker仅20:00至次日06:00领取且低于ETF优先级；单worker、模型线程1。长历史首次训练在开发机；当月已注册工件可复用。
- `ETF_GOLD_ENABLED=false`暂停领取黄金任务并保留历史；`ETF_GOLD_LLM_ENABLED=false`单独停用黄金付费解释。原ETF日终及预算不改变。
- 新迁移V12/V13只增黄金表。首选 `deploy/windows/disable-gold.ps1`局部回退；切V11旧应用时先暂停仅GOLD队列，不恢复旧数据库，不覆盖发布后的ETF业务记录。

实际部署版本、测试和数据核验结果见本轮验收报告；协议不能替代运行证据，也不授予未来发布或付费权限。
