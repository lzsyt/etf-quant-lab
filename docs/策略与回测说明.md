# 策略与回测说明

研究池为核实过的510300、510500、159915。数据源及交易属性证据见[数据源与交易规则](数据源与交易规则.md)。真实入库日线共4214条，2021-01-04至2026-10-23；159915缺少2021-02-08。免费数据源可能失败，系统保留失败状态，不用演示行情补齐真实数据。

规则策略包含MA20/MA60、RSI14滞回、MACD、20日趋势动量和相对强弱轮动。动量等权分配正信号品种；轮动选较强品种优先配置。LightGBM及XGBoost分别训练1日和5日模型，共12个真实模型，另提供Logistic Regression扩展入口。特征包括收益率、均线比值、成交量变化、波动率、RSI、MACD、动量及相对510300的强弱。

训练按时间依次分为60%训练、10%独立概率校准、10%验证、20%留出测试。任何标签结束日进入下一分区的样本均清除。另做三折Walk-Forward，每折独立训练/校准；不随机打乱，不补未来值，不将缺失交易日压缩。上线模型禁止回填早于工件完整输入截止日的预测，该`data_cutoff`超过45日则停止使用；自动任务按月检查并串行补训。这里的完整输入截止日不等于实际fit截止：保存的模型只在训练段拟合、校准器只在校准段拟合，当前工件没有在留出评价后用所有已知标签重新训练。日期门禁不保证参数使用了最近45日的标签，详细证据及迭代要求见模型档案（内部资料，未随源码上传）与迭代路线（内部资料，未随源码上传）。

回测信号使用T日收盘及此前数据，最早在后续真实交易日开盘估计成交。日线数据不能证明开盘时真实流动性，本模型明确称为`NEXT_OPEN_DAILY_ESTIMATE`。买入增加价差与滑点、卖出扣减；价格超出当日日线区间、停牌/零成交、涨跌停、成交量限制、T+1或资金/仓位约束均可拒单。每笔订单保留原因，不把未成交订单记为成交。

默认独立虚拟本金100000元，佣金万三且每笔最低5元，滑点5bp、价差2bp，成交量参与率上限1%。所有比较组使用同一资金、风险、交易规则及区间；含现金基准和风险约束买入持有。买入持有在最初5个有效建仓交易日逐步买入，随后持有、不调仓。研究初期三次使用旧定义的实验已经标为SUPERSEDED，完整数据保留；正式报告只使用修正后的复测结果。

资金曲线、回撤、年化收益/波动、Sharpe、Sortino、手续费、胜率、盈亏比与换手均由实际模拟成交计算。无交易或零波动时无定义的比率返回null，不人为填零。Sharpe无风险利率取0；年化采用252个交易日。已平仓胜率不是未来上涨概率。

RAW用于可成交价格；QFQ/HFQ数据口径独立保存，不能直接拿复权价格撮合。分红和拆分引擎支持经核实的事件、除息日应收及支付日入现金，未核实的事件不计入。当前真实报告缺少完整核实分红，仅为价格收益，不能解释为含分红总回报。

实验A是纯机器学习；B是有来源的LLM事件信号；C是机器学习与LLM融合。B/C缺少历史点时新闻，历史回测明确不可评估。上线固定70/30融合只是实验性分数，不是校准概率。正式融合评价需积累至少150个到期前瞻信号日，并使用训练段事件校准、验证段权重选择和独立测试；不能因固定权重结果好看就声称显著改善。

当前正式融合SQL筛选ML及时结果，但尚未独立筛选相连LLM预测的及时性；正式采用评价结论前须补齐该时间门限。历史ML回测与在线目标权重分配也并非完全一致，比较收益时须保留这一限制，见交易语义（内部资料，未随源码上传）和融合档案（内部资料，未随源码上传）。

实际数值见真实行情回测报告（内部资料，未随源码上传）。12模型留出准确率约46.5%至58.2%，不能据此证明稳定获利；三个区间中机器学习扣费后收益均未超过现金基准。研究池是当前存续品种，存在选择偏差，窗口部分重叠，不是独立重复检验。

复现：保持Python3.12与锁定依赖，将对应`.data.json.gz`解压构造`TrainRequest`后调用`train_model`；既有12个输入已复现出一致工件ID。运行`deploy/scripts/run-research.py`可通过持久任务重建真实训练和三个回测窗口。身份摘要覆盖的数据或配置变化会产生新ID；算法实现、全部超参数和依赖未自动全部进入ID，相关改动必须显式升级版本键并保持旧工件及预测可追溯，不能声称任意代码变更都会自动生成新版本。
