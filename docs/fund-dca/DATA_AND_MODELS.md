## 离线复现

在仓库根目录使用既有Python环境和本次冻结的公开净值输入；输出到新目录，不联网、不写数据库、不收费：

```bash
.venv/bin/python quant-engine/scripts/fund_research_audit.py \
  --nav-input LOCAL_PRIVATE_ARCHIVE \
  --output LOCAL_PRIVATE_ARCHIVE
```

复现生成每基金研究JSON、六份模型、summary.json和comparison.json。模型ID和生成时间为新值；比较窗口、现金流与费率是脚本内明确研究假设，不代表用户实际到账记录。稳定归档中的 `evidence/real-research-final` 也可作为nav-input。
